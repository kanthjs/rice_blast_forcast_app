# คู่มือการใช้งาน (Usage Guide)

## เริ่มต้นใช้งาน

### ขั้นตอนที่ 1: เลือกพื้นที่

1. **คลิกบนแผนที่** - คลิกตรงตำแหน่งแปลงนาที่ต้องการ
2. **ใช้ตำแหน่งปัจจุบัน** - กดปุ่ม "Use Current Location"
3. **พิมพ์พิกัด** - ใส่พิกัด Lat, Long แล้วกด "Go"

### ขั้นตอนที่ 2: ตั้งค่าวันที่

- **Start date**: วันเริ่มต้นการพยากรณ์
- **End date**: วันสิ้นสุดการพยากรณ์
- **Past 3 days**: ดูข้อมูลย้อนหลัง 3 วัน

### ขั้นตอนที่ 3: เลือกโมเดล

| โมเดล | คำอธิบาย | เหมาะสำหรับ |
|-------|----------|-------------|
| Classic | พื้นฐาน | ประเมินเบื้องต้น |
| EDRM | ขั้นสูง + อายุข้าว | ต้องการความแม่นยำ |
| BUS | BUS Score | ใช้ตามมาตรฐาน |
| BLASTAM | ทำนายการระบาด | พยากรณ์ล่วงหน้า |
| EPIBLA | ประเมินความรุนแรง | วางแผนการฉีดพ่น |

### ขั้นตอนที่ 4: อ่านผลลัพธ์

- **สีเขียว (Low)**: ปลอดภัย
- **สีเหลือง (Medium)**: เฝ้าระวัง
- **สีแดง (High)**: ควร Action ทันที

## การแก้ไขเอกสาร

เอกสารทั้งหมดอยู่ในโฟลเดอร์ `docs/` สามารถแก้ไขได้โดย:

1. เปิดไฟล์ `.md` ด้วย text editor (VSCode, Notepad++, etc.)
2. แก้ไขเนื้อหา
3. บันทึกไฟล์

### ไฟล์เอกสาร

- `docs/README.md` - ภาพรวมโปรเจกต์
- `docs/models/classic.md` - Classic Model
- `docs/models/edrm.md` - EDRM Model
- `docs/models/bus.md` - BUS Model
- `docs/models/blastam.md` - BLASTAM Model
- `docs/models/epibla.md` - EPIBLA Model
- `docs/usage_guide.md` - คู่มือการใช้งาน (ไฟล์นี้)
